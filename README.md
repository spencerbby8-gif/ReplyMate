# ReplyMate

Personal Android AI messaging assistant. This repository currently contains **Phase 1: foundation** only: an encrypted local persistence foundation, settings scaffold, user-owned personalization model, Material 3 shell, setup UI, and deterministic prompt assembly. Message notification capture, AI provider calls, and message sending are deliberately not implemented yet.

See [`docs/REPLYMATE_SPECIFICATION.md`](docs/REPLYMATE_SPECIFICATION.md) for the approved architecture and Phase 1 boundary.
